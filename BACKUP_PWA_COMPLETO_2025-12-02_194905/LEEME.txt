💡 FLUJO DE USO

  1. Ejecutar npm run dev
  2. Abrir http://localhost:3000
  3. Llenar formulario (nombre, URL stream, logo)
  4. Personalizar colores y tema
  5. Ver preview en tiempo real
  6. Click en "Generar PWA"
  7. Click en "Descargar ZIP"
  8. Desplegar en servidor HTTPS
  9. ¡Listo! Tu app es instalable

📱 ARCHIVOS PWA GENERADOS

  Cuando generas una PWA, se crean:

  ✓ index.html          → App completa standalone
  ✓ manifest.json       → Configuración PWA
  ✓ sw.js              → Service Worker
  ✓ app.js             → Lógica JavaScript
  ✓ styles.css         → Estilos personalizados
  ✓ icon-192.png       → Icono pequeño
  ✓ icon-512.png       → Icono grande
  ✓ logo.png           → Logo de la radio
  ✓ README.md          → Instrucciones

  Todo empaquetado en un ZIP listo para desplegar.

═══════════════════════════════════════════════════════════════

🌐 DESPLIEGUE

  1. Descargar ZIP generado
  2. Descomprimir archivos
  3. Subir a servidor con HTTPS (obligatorio)
  4. Abrir desde navegador móvil
  5. Instalar desde "Añadir a pantalla de inicio"

═══════════════════════════════════════════════════════════════

📱 CONVERSIÓN A APK

  Opción 1: Bubblewrap CLI
  ─────────────────────────
  npm install -g @bubblewrap/cli
  bubblewrap init --manifest https://tudominio.com/manifest.json
  bubblewrap build

  Opción 2: PWABuilder.com
  ────────────────────────
  1. Ve a https://www.pwabuilder.com/
  2. Ingresa tu URL
  3. Descarga paquete Android
  4. Publica en Google Play

🐛 SOLUCIÓN DE PROBLEMAS

  ❌ Node.js no instalado
     → Descargar de https://nodejs.org/

  ❌ Puerto 3000 ocupado
     → Vite usará otro puerto automáticamente

  ❌ Error al instalar
     → npm cache clean --force
     → Remove-Item -Recurse -Force node_modules
     → npm install

  ❌ Stream no reproduce
     → Verificar URL correcta
     → Verificar CORS habilitado
     → Verificar formato (MP3, AAC, OGG)
