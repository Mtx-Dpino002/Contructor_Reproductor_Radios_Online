## 🐛 PROBLEMAS COMUNES

### "Cannot find module 'lottie-react'"
```powershell
npm install lottie-react --save
```

### "Port 3000 already in use"
```powershell
npm run dev -- --port 3001
```

### Animaciones no cargan
- Verificar conexión a internet
- Las URLs de lottie.host son correctas
- Esperar 2-3 segundos en primera carga
