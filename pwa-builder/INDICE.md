## 📱 ¿QUÉ HACE ESTE PROYECTO?

**PWA Builder** es una aplicación web que permite crear Progressive Web Apps (PWAs) para radios online **sin escribir código**.

### Características principales:
- ✅ Constructor visual tipo drag-and-drop
- ✅ Vista previa en tiempo real
- ✅ Personalización completa (colores, logos, temas)
- ✅ Reproductor de audio integrado
- ✅ Exportación a ZIP
- ✅ Conversión a APK para Android
- ✅ PWA instalable desde navegador
